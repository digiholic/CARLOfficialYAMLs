# CARLOfficialYAMLs
A place to host the most up-to-date versions of game settings for the Competitive Archipelago Racing League.

# Categories
YAMLs can be in one of three categories:
- Candidate - this game is a suggested addition to CARL and has not yet been reviewed and accepted.
- Ratified - this game has been accepted and is part of the available games that can be rolled during a match.
- Retired - this game was previously ratified, but has now been removed. YAML is kept here for archival purposes, or to potentially be salvaged and re-used with some changes.

# Suggesting New Games
Considerations for choosing a good competitive game, in rough order of importance:
- **Stability**: The world should be basically finished, have finished and robust logic, and be always completable without Game Master intervention.
- **Familiarity**: While "Popularity" sounds cynical, it is nonetheless important to consider a game that people are at least passingly familiar with, as competitors are expected to know and own every game possible in a season before joining.
- **Skill Expression**: The game should allow for great players to gain time over good players. There are many ways for a game to be skill-expressive, the logic could have a lot of complicated rules and routing the game requires familiarity with access routes. The game itself could just be difficult, and being able to beat the game in few attempts could be important. A game that is on-rails or time-based is not good competition.
- **Free-form**: A game should provide options, where player choice can lead to significant outcomes. Games that are linear series of locks and keys where each check is received in the same order are less desirable.
- **Meaty**: A game should have enough content in it to warrant being one third of a race. A game that can be completed in under thirty minutes is not a good candidate to have with other games that take 2-3 hours.
- **Obtainable**: We're expecting competitors to own _every_ game that can be rolled. Let's do them a favor and not suggest games that require being dumped from a LodgeNet device or costs $6,000 on eBay, yeah?

If you feel you know of a game that fills every qualification, submit a pull request adding the game's YAML to the `candidates` folder.
